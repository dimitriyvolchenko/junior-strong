Установка и первые шаги

1. Откройте готовое приложение

Репозиторий приложения: dimitriyvolchenko/junior-strong. Приложение доступно: открыть «Сила расти».

  1. Загрузите все файлы распакованного архива в корень выбранного репозитория: они лежат вместе, без вложенных папок.
  2. Откройте Settings → Pages. Выберите Deploy from a branch → main → /(root) → Save.
  3. Дождитесь ссылки, которую покажет Pages, и откройте её на телефоне. Загрузка одного index.html без остальных файлов не работает.

2. iPhone и iPad

1

Откройте Safari

Перейдите на опубликованный сайт и дождитесь загрузки программы.

2

Поделиться ↗

В меню Safari выберите «На экран Домой».

3

Добавить

Включите «Открывать как веб-приложение», если такой пункт есть. Значок появится на домашнем экране.

Это схема шагов, а не скриншоты iOS. Названия и расположение пунктов могут отличаться в версиях системы.

Android и Windows

В Chrome/Edge нажмите «Установить» в приложении либо найдите установку сайта в меню браузера. На Android пункт может называться «Добавить на главный экран».

Первое открытие требует интернета. После загрузки и подготовки кеша проверьте повторный запуск без сети на своём устройстве.

3. Первое занятие

  1. Родитель сначала читает раздел «Родителям» и проверяет подходящий старт со специалистом.
  2. Выберите дату и день недели. Для силового занятия взрослый остаётся рядом и отмечает переключатель.
  3. В тягах и сгибаниях взрослый сначала выбирает рабочий вес: без веса для обучения, 0,5 кг либо 1 кг на одну руку. Выбор зависит от техники и лёгкости движения. После разминки выполните лёгкий подход, укажите реальный результат и отметьте галочку.
  4. Сравнение покажет отличие от плана. Не нужно превышать план ради похвалы.
  5. Откройте дневник. В конце недели скачайте резервную копию в разделе «Родителям».

4. Обновление и перенос

Расписание меняется через полный файл program.json. После его обновления в GitHub нажмите в приложении «Обновить программу». Сохраняйте прежние ID упражнений, если движение остаётся тем же. Результаты содержат снимок прежнего плана.

Ручной JSON закрепляется до явной проверки серверной версии. Галочки и результаты хранятся только в браузере данного устройства. Для другого устройства скачайте и восстановите историю JSON; облачной синхронизации нет.

Силовые упражнения одному выполнять нельзя. Для гантели есть выбор 0,5 или 1 кг после проверки техники; без выбора взрослого такой подход закрыт. Блоковый тренажёр с шагом 5 кг, турник и лестница пока не включены. Не переходите автоматически с 0,5 на 1 кг. Приложение — дневник и общий шаблон: подходящую технику проверяют очно.
