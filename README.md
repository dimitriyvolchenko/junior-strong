# Сила расти

Домашняя академия движения для ребёнка 8 лет и родителей. Стартовая программа на первые две недели: два силовых занятия всего тела (понедельник и четверг), три дня игр, координации и подвижности. Все силовые упражнения требуют непосредственного присмотра взрослого, обученного технике. Первые занятия нужно индивидуально проверить с детским тренером; при заболеваниях или ограничениях согласовать с педиатром.

Это начальный шаблон, а не гарантия безопасности или размера мышц к определённому возрасту. Взрослый тренажёр с шагом 5 кг, турник, лестница и гантель 1 кг не включены в стартовые занятия. По умолчанию все упражнения без дополнительного веса.

## Размещение

Все файлы приложения лежат на одном уровне. Распакуйте архив и загрузите файлы прямо в корень отдельного репозитория GitHub. Не нужно создавать вложенные папки. В репозитории: Settings → Pages → Deploy from a branch → main → /(root) → Save. Дождитесь появления адреса сайта в Pages. Репозиторий приложения: https://github.com/dimitriyvolchenko/junior-strong . Актуальный адрес публикации отображается в Settings → Pages этого репозитория.

Сборка, Node.js и серверная часть для размещения не нужны. Не запускайте приложение двойным щелчком по локальному index.html: для JSON, установки и офлайн-режима нужен HTTPS, например GitHub Pages.

## Установка

iPhone/iPad: откройте опубликованный сайт в Safari → Поделиться → На экран «Домой» → Добавить. Если есть переключатель «Открывать как веб-приложение», включите его. Android: меню Chrome → Установить приложение / Добавить на главный экран. Windows: кнопка установки в Chrome/Edge или соответствующий пункт меню, если браузер предлагает установку.

Первый запуск должен пройти с интернетом. Дождитесь загрузки программы и завершения установки кеша; перед поездкой проверьте открытие без сети. Не все браузеры поддерживают установку и сохранение одинаково. Офлайн-проверка в этой среде выполнена на логике обработчика кеша; запуск в авиарежиме следует проверить на целевом телефоне.

## Дневник

Выберите дату, взрослый подтверждает присутствие для соответствующих заданий. Запишите фактические повторы/минуты/секунды и массу инвентаря. 0 кг означает без дополнительного отягощения, а не отсутствие нагрузки на мышцы. Галочка относится к одному подходу. Можно отметить подход без числового результата, если количество не считали; дневник явно покажет отсутствие числового факта. Приложение не начисляет бонусов за превышение плана.

Подтверждение взрослого сбрасывается при смене даты, перезагрузке и импорте. Это напоминание, не пароль и не замена реальному присмотру.

История сохраняется локально на текущем устройстве в текущем браузере/профиле. Автоматической облачной синхронизации нет. Другой телефон, браузер или установленное приложение могут иметь отдельную историю. Смена домена, удаление приложения или очистка данных браузера могут убрать доступ к записям.

Родителям → Скачать историю JSON. Для переноса сохраните файл и восстановите его на другом устройстве через Родителям → Восстановить историю. Импорт добавляет записи, а совпадающие подходы заменяет после подтверждения. Не публикуйте личную историю ребёнка в открытом репозитории.

## Обновление программы

Отредактируйте полный файл program.json в репозитории и увеличьте version. После Commit и обновления Pages приложение загрузит новую программу при следующем запуске онлайн. Кнопка «Обновить программу» / «Проверить обновление» делает явную проверку. Если содержимое изменилось, потребуется подтверждение. История остаётся: план каждого записанного подхода сохраняется рядом с фактом и не заменяется новыми нормами.

Можно загрузить полный JSON вручную в разделе «Родителям». Такой вариант закрепляется на устройстве и не заменяется автоматически серверной версией. Для возврата к версии репозитория используйте явную проверку обновления и подтвердите замену.

Не меняйте id существующего упражнения, если это всё ещё то же движение; для другого движения создайте новый id. Сохраняйте уникальные ID упражнений и дней. Не переносите упражнение в другой день с тем же ID для уже записанных дат. Изменение количества подходов может скрыть лишние старые подходы в экране занятия; все сохранённые записи по-прежнему видны в дневнике и резервной копии.

Формат schemaVersion:1, age:8, пять будних дней; ровно два силовых дня — Пн/Чт; 1–2 подхода, до 15 повторов; отдельные единицы seconds и minutes. loadKg ограничен 0–1 кг, но это только техническая граница, а не разрешение назначить ребёнку 1 кг. Любое дополнительное отягощение требует adultOnly:true и индивидуальной проверки специалистом. Параметры валидируются до применения; медицинскую пригодность формат не проверяет. Все стартовые веса — 0 кг.

Для обновления интерфейса замените index.html/styles.css/app.js и связанные файлы; увеличьте VERSION в sw.js. При следующем подключении приложение предложит обновление. Сохраняйте домен, путь приложения и ключ localStorage junior-strong-v1, чтобы сохранялся доступ к истории. Перед обновлениями всё равно делайте резервную копию.

## Что входит

index.html — интерфейс; styles.css — оформление; app.js — дневник, проверка и обновление JSON; program.json — расписание; sw.js — офлайн; manifest.webmanifest — установка; hero.svg и icon.svg — графика; три PNG-иконки; README.md — описание; INSTALL.html — краткая иллюстрированная инструкция.
